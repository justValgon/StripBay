(Deutsch: README.de.txt)

Put the two files from the EuroScope plug-in SDK into this folder:

  EuroScopePlugIn.h
  EuroScopePlugInDll.lib

You find them in the EuroScope installation folder, subfolder
"PlugInEnvironment" (or in one of your existing plug-in projects).
The project does not build without these files.
